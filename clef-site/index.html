An exhibit about representation engineering

When an AI agent reaches for a tool,
what is it thinking?

Type a shell command an agent might run. A small language model (Qwen 2.5, 0.5B) reads it, and we look inside it — at the pattern of numbers in its middle layers — to judge whether the command means harm. Nothing you type is ever executed.

Station 2 · The alarm line

Every command lands somewhere on one line.

The model's reading becomes a single number: how much more "harm-like" this command looks than the most harm-like of five ordinary commands (cargo build, git status…) in the same situation. Past the red line, the command is refused. The grey and red dots are 50 real commands we tested it on — grey meant no harm, red meant harm. Where they overlap, it makes mistakes.

Station 3 · Which pieces lit up

The model reads in pieces called tokens.

Each piece of your command gets its own reading. The brighter the piece, the more harm-like it looked to the model on its own. The decision itself uses the average over all pieces.

Station 4 · Three kinds of harm

We taught it three directions.

From pairs of commands — one harmful, one similar but harmless — we found three directions in the model's internal space: destroying things, reading secrets, and sending data away. This is how far your command points along each. Right of centre points toward that harm; left points away from it.

How it works, briefly

  1. Collect pairs. 24 pairs of commands: one harmful, one harmless, often with the same verb (rm -rf ~/Documents vs rm -rf ./dist).
  2. Look inside. Run each through the model and record the numbers at layer 16. Harmful and harmless commands push those numbers in different directions.
  3. Measure new commands against those directions and compare with ordinary commands in the same situation.

Limits. It's a small model and a small training set. It still mistakes some ordinary downloads for data theft, and it misses harm it was never shown (force-pushing over a branch, killing every process). It judges commands; it does not detect prompt injection. The method comes from Zou et al., Representation Engineering (2023).
