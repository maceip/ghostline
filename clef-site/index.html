GHOSTLINE · Pre-decode activation guard (RepE + Cloudflare Clef-Flash pipeline)

When an AI agent reaches for a tool,
what is it thinking?

A language model (Qwen 2.5 0.5B or Cloudflare clef-flash) reads a shell command an agent wants to run. Instead of trusting its answer, Ghostline opens the residual stream, probes the mid-layer activation trace with Representation Engineering (RepE), and routes ambiguous cases through the Clef joint schema head. Everything below is measured live on the model. Nothing you type is ever executed.

Active Intervention · Speculative KV-Cache Rollback

↺ Block (403) vs. Layer-16 Clamp & Rollback

Instead of halting the agent with a hard HTTP 403 refusal, Ghostline can clamp the destructive direction out of the Layer-16 residual span, truncate the upper-layer KV cache back to the tool-call boundary, recompute Layers 17–23, and steer the agent to a safe CLI alternative.

How Ghostline was built

  1. Collect pairs. 24 pairs of commands: one harmful, one harmless, often with the same verb (rm -rf ~/Documents vs rm -rf ./dist).
  2. Look inside. Run each through the model and record the numbers at layer 16. Harmful and harmless commands push those numbers in different directions.
  3. Measure new commands against those directions and compare with ordinary commands in the same situation using prefix KV-cache slicing. The alarm line was placed to catch as many harmful training commands as possible while letting at most one in ten ordinary ones trip it.

Limits. It's a small model and a small training set. It still mistakes some ordinary downloads for data theft, and it misses harm it was never shown (force-pushing over a branch, killing every process). It judges commands; it does not detect prompt injection. The activation-probing method comes from Zou et al., Representation Engineering (2023), paired with the Cloudflare clef-flash joint schema head.
