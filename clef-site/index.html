THE STORY

Trust is not a prompt. It’s a reading.

01 · THE PROBLEM

?

intent or injection

An agent’s tool call can be planted. A file, a comment, a web page — anywhere the context flows. The command string looks like yours. The words prove nothing.

02 · THE IDEA

68%

of decoder depth

Representation engineering reads the model’s own activations instead of its words. The residual stream at layer 16 already carries the intent of the call — destruction, theft, exfiltration — before a single command is executed.

03 · THE PROOF

36

calls, judged live

The exhibit runs the real thing: a calibrated read over every call, against a baseline from the same prompt. Every number on this page is a capture from a running engine — nothing is invented.
